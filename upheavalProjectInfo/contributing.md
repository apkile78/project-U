# Contributing / Working Rules

This is primarily a solo project, but these rules also apply when using AI coding tools.

## Before Coding

Read:

* `README.md`
* `TODO.md`
* relevant architecture section

Know the current milestone.

## During Coding

* Keep changes focused.
* Avoid unrelated cleanup.
* Prefer explicit code over clever code.
* Add debug visibility when creating a complex system.
* Test the behavior you changed.

## When Using AI

AI-generated code is treated exactly like human-written code:

**The project owner is responsible for understanding and testing it.**

Do not paste huge generated systems into the repository simply because they compile.

## Before Commit

Ask:

* Does it work?
* Did I test it?
* Did I accidentally change unrelated behavior?
* Is the architecture still understandable?
* Did I update TODO/decision docs if necessary?

## No Scope Creep

New ideas go into `IDEAS.md`.

They do not interrupt the current milestone unless they are genuinely necessary.
